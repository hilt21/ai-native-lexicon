# 网站品牌素材交付

对应 [素材票 #45](https://github.com/hilt21/ai-native-lexicon/issues/45)。10 项基础素材的实际文件、原稿章节、源 SHA-256、提取区域、源尺寸和制作方式维护在 [素材索引](../../../public/brand/assets.json)。

本文件描述已合并的 v1 原始提取稿及其质量边界，继续用于既有媒体投影。后续本地首页已验收的 v2/v3 路径稿与手机导出由 [首页实施规范](homepage-hero-artwork-plan.md#响应式与素材契约) 选择；下述 245px 限制及被拒绝的早期生成式候选不约束该独立版本，也不表示当前首页仍使用 v1。

## 查看与消费

- [实际尺寸预览](../../../public/brand/preview.html) 展示浅/深背景、16/32/64 px 符号、24 px 类型图标、120 px 起字标和 245 px 主视觉。
- [矢量对照预览](assets/vector-preview.png) 与 [原始像素主视觉预览](assets/mascot-preview.png) 可直接查看。九项标志的透明原像素参考图位于同目录，由索引逐项引用。
- 网站素材位于 `public/brand/`。字标/符号/图标提供 SVG 明暗变体；主视觉提供透明 PNG 母版和 320/491 px WebP。生产链接必须应用部署 base。

## 制作与限制

标志与图标从原稿的墨黑/绿色区域描摹为路径，统一使用现有品牌色；原图仅含 JPG，因此这些是源图派生矢量稿，而非取得了原始设计矢量文件。几何细节和比例已经与原图对照，北极星独立符号及独角兽组合的内镂空在两种主题中保持白色。

主视觉保留图版 01 的原始 JPEG 像素，用原稿轮廓的 SVG 遮罩去除版面文字与外部纸底后导出。有效原生区域为 **491 × 626 px**；491 px WebP 的显示宽度最多为 **245 CSS px（2×）**，避免宣称新增高清细节。背景分离的生成式候选有重绘，已拒绝使用；生产素材不包含生成式候选像素。

原稿五张 JPG 未改变；源摘要可由索引逐项校验。主视觉边缘保留原图抗锯齿和纸色内部形态，小尺寸派生标志忠于原稿的光学表现；未来有真正的设计源文件时，应以单独版本替换并再次检查，不覆盖原稿。

## 验证

`node --test tests/brand-assets.test.mjs` 检查 10 项身份与源摘要、文件存在、自包含 SVG 在目标尺寸的真实渲染、透明背景及主视觉源分辨率上限。实际形态、双主题边缘及光学辨识以预览为检查依据；这些检查不证明网站升级已经完成。
