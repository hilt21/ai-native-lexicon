## 已确定的范围

这是面向技术读者的编辑式知识网站，沿用 Astro / Starlight、原生 CSS、现有语义 token、Georgia 展示标题与系统正文/等宽字体。设计参数保持 `DESIGN_VARIANCE=6`、`MOTION_INTENSITY=4`、`VISUAL_DENSITY=3`；沿用既有入场效果与 reduced-motion，没有新增动效。

| 优先级 | 已验收决定 | 完成条件 |
| --- | --- | --- |
| P0 尺度与位置 | 宽桌面角色 330 CSS px，右栏 370px，整体向上 20px；完整保留角色、弓箭与坐骑 | 人物不压迫标题、说明和操作，轮廓无裁切，容器无溢出 |
| P0 Dark 资产 | 采用 v3 暗部融合版：披风、衣装和靴子接近页面暗色，亮部集中在脸、手、独角兽头 | 识别部位清楚，暗部与页面融为一体；不要求复制 Light 的大面积亮度或视觉重量 |
| P1 北极星 | 箭尖沿用酸绿 `#C8FF3D`、0°、内部白色镂空；固有坐标锚点随角色等比缩放 | 箭尖清楚，姿态、比例和品牌形状保持，装饰图不形成操作热点 |

## 响应式与素材契约

具体媒体查询以 [CSS](../../../src/styles/custom.css) 和 [HeroArtwork](../../../src/components/HeroArtwork.astro) 为准。下表按默认 16px 根字号描述常用视口；保留现有边界规则，不在本次文档同步中改代码。

| 视口 | 角色宽 / 右栏宽 | 位置与资源 |
| --- | --- | --- |
| ≥1440px | 330 / 370px | 上移 20px；桌面素材 |
| 1201–1439px | 310 / 350px | 上移 20px；桌面素材 |
| 801–1199px | 260 / 280px | 无额外位移；桌面素材 |
| 恰好 1200px（75rem） | 310 / 350px | 尺寸命中后一个规则，位移仍命中紧凑规则，为 0 |
| ≤800px（50rem） | `min(100%, 480px)` / 单栏 | 无位移；手机素材，CTA 后、左对齐 |

Hero 的单栏查询为 `max-width: 50rem`，手机页头图标查询为 `width < 50rem`。因此恰好 800px 时，Hero 为单栏而页头显示桌面文字选择器；后续检查要覆盖这个边界。360px 人物实际宽 328px，390px 为 358px；较宽单栏以 480px 为上限。保留两主题共同的 1111 × 1416 比例和透明外围。

| 消费位置 | Light | Dark | 网页导出 |
| --- | --- | --- | --- |
| 桌面首页 | [v2 路径稿](hero-artwork/v2/README.md) | [v3 暗部融合路径稿](hero-artwork/v3/README.md) | 340 / 680px WebP，DPR 1 / 2 |
| 单栏首页 | 同一 v2 Light 母稿 | 同一 v3 Dark 母稿 | [手机 480 / 960px WebP](hero-artwork/mobile/README.md)，DPR 1 / 2 |
| 默认 OG、Speaking Guide 图片 | 原 v1 素材 | 原 v1 素材的现有表现 | 沿用既有媒体投影，不自动传播首页的新主视觉 |

v2 是经用户授权的生成式重制加路径描摹，v3 在既有 SVG 内部调整明暗；来源、提示词、mask、文件摘要及生成方式由各素材交付文档维护。它们不冒充原始设计矢量文件。原稿及 v1/v2 Dark 对照保留。当前资产已经可用，后续开发不以重新获取素材为前置条件。

## 页面与实施边界

- `HeroArtwork` 为 `aria-hidden` 装饰元素，使用固定比例、CSS `image-set` 和原生 `[data-theme]`，通过 `pathWithBase` 选择资源；Light/Dark/Auto 与系统切换共用同一主题控制器。
- 手机 Header 只显示既有原生选择器，保留查询、有效片段、locale/base、焦点与重载状态。图标收起状态不显示语言名称，完整选项仍在原生菜单中。普通阅读页维持原有菜单。
- `Footer.astro` 只为首页追加本地化版本文字；原生底部导航、编辑链接、更新时间、署名和其它页页脚沿用默认组件。
- 继续保留一个文本 h1、说明、主次 CTA、四任务区、精选概念、分类及 canonical 数据集入口。记录身份、知识内容、机器导出、索引和翻译政策沿用现有契约。

当前共享显示规则由 [设计系统](../redesign-system.md) 维护。后续开发先核对本规范与实际代码，再只修改有明确新需求的差异；内部步骤不按素材、组件或测试另拆票。

## 验收与验证边界

- 检查两语言 × Light/Dark、桌面与单栏边界；主视觉不相交、不拉伸、不裁切。390 × 844、360 × 800 的说明与主 CTA 优先完整可见。
- 保留原生主题/语言、Pagefind、菜单、键盘焦点、跳至内容、计算对比度和 reduced-motion；图片可解码，DPR 1/2 与 Auto 请求正确素材。
- 产品变更按 [贡献要求](../../../CONTRIBUTING.md#validation) 执行 check、test、生产子路径 build 和现有 browser 套件，保留严格 BFCache/reload 断言。本次仅同步文档，检查链接、命令、源码与记录的一致性即可。
- 既有性能测量仅是当时的本地实验室证据；真实用户 INP、实际 400% 缩放、屏幕阅读器和真机菜单仍未验证。上线后用户任务/识别测试属于效果评估，不追加为本轮工程验收门槛，也不据此承诺增长或品牌记忆提升。

本轮用户验收代表本地设计结果获认可；主分支合并、线上发布和上线效果各自需要对应的实际证据。历史迭代和最新工程结果统一从 [验收记录](../../audits/hero-editorial-acceptance.md) 查阅。
