# 保留英文规范文本并独立维护翻译资产

Concept、Primitive 正文与 taxonomy 语义采用英文规范文本，中文译文作为独立翻译覆盖层维护；页面、搜索与 Copy 从同一个解析结果取得实际语言与覆盖状态。与复制整份中文知识记录相比，这个边界保留唯一身份、关系和证据状态，并让译文审查及逐单元过期判断独立进行；Speaking Guide 与 Skill Map 保留各自原始语言版本。

只有已审查且来源指纹当前的单元进入中文正文。数组译文绑定完整有序拥有数组，避免增删或重排后附着到错误成员；引用定义继续解析原 Concept。机器导出及其内容版本保持读取规范记录，中文渲染不建立第二份规范知识或新的导出契约。详见 [翻译覆盖层契约](../design/translation-overlay.md)。
