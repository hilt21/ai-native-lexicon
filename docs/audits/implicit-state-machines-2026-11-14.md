# AI Native Lexicon state inventory

Baseline: `0f8fcb4` (PR #61), reviewed 2026-11-14. Scope: checked-in browser behavior, state inherited from the configured Starlight components, content and generated artifacts, verification, and CI. A state machine here has an event or input that changes allowed behavior or a visible outcome. Static graph edges and computed layouts without memory are not runtime machines. This is a source audit; browser, assistive technology and social platform evidence have separate scopes.

## Verification boundaries

- Loader regression deliberately delays the first generation until the new one has installed its watcher. It checks store ownership and that a third load detaches the current watcher. Existing tests cover serialized refresh and recovery after an invalid filesystem update.
- The production browser suite includes a controlled pending clipboard write, repeated activation, focus retention, reconnect, rejection and retry. Existing checks separately exercise real clipboard payloads, localization and normal permission failure.
- No routes, IDs, datasets, workflows, content schemas or translation review decisions change.
