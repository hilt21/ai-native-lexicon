---
title: About the lexicon
description: Why this open, data-first lexicon exists and how it is maintained.
---

AI-native software engineering is creating a new working language: terms for context, agency, execution, evidence, and organizational design. This project gives that language a durable, inspectable home.

## Editorial stance

Entries are concise working definitions, not claims of universal consensus. Each concept should help a practitioner make a decision, name a trade-off, or critique a system. The maturity label distinguishes established ideas from language that is still moving.

## Data first

Every concept is stored as a validated YAML record. The website, category indexes, relationships, and machine-readable exports are projections of the same source. That keeps the publishing layer thin and leaves room for a concept graph, a timeline, and richer datasets without migrating the content.

## Open by default

The lexicon improves through precise proposals: a clearer boundary, a better example, a missing relationship, or evidence that a term is used differently in practice. See the contribution guide in the repository before opening a pull request.
